# concept-learning-material · 概念学习资料生成 Skill

> 项目级 Skill，路径：`.workbuddy/skills/concept-learning-material/SKILL.md`
> 随仓库走；任何人 clone 本仓库后，在该项目内即可直接使用。

## 一、Skill 是什么 / 做什么

**Skill = 一份"经过验证、可重复执行"的工作流说明书。**

本 Skill 的唯一职责：给定一个概念名称（任意领域，例如"主成分分析"、
"贝叶斯推断"、"蒙特卡洛模拟"、"抽样分布"），生成一份**结构完整、内容
自洽、来源可核查**的单文件 HTML 学习资料。

它**不绑定任何具体概念**——传入新概念时，流程与产出标准完全一致。

## 二、产出文件的标准结构

每份学习资料（HTML 单文件）必须包含下列章节，缺一不可：

1. **一句话理解**：用学习者自己的话，对概念做不超过两句的概括。
2. **学习目标**：3–5 条，本次要回答的核心问题。
3. **核心机制与组成**：用文字 + 必要的公式 / 图示，把"它为什么是这样"
   讲清楚。
4. **一个具体应用场景**：选一个能"落地讲出来"的真实问题，说明该概念
   在该场景中扮演什么角色、解决了什么难点。**禁止泛泛而谈**。
5. **容易混淆的问题与使用边界**（至少 3 条）：写明该概念的失效条件、
   与邻近概念的区别。
6. **自测问题**：用于检验"理解"而非"记忆"的问题，至少 3 条。
7. **可核查的资料来源**：每条引用必须给出 URL，并标注**实测访问状态**
   （状态码 + 验证日期）。**非 200 一律剔除，不得凭印象填写**。
8. **核查记录**：说明本次生成方式、来源验证方式、待人工复核项。

## 三、硬性约束（不可跳过）

> 这两条是质量底线。任何一份产出如违反，需重新生成。

1. **来源不得伪造**：每一条准备写入资料的链接，必须实际发起 HTTP 请求
   验证状态码。非 200 一律剔除，不得凭记忆或训练数据填写。
2. **解释不得照搬**：读完来源后，**先合上资料**，用自己的话重述。禁止
   复制来源段落，不得改写几个词就当作"自己的理解"。

## 四、自检清单（全部通过才算完成）

生成完一份 HTML 后，对照以下 9 条逐条勾选：

- [ ] 一句话理解是否真正抓住了概念的核心？（而非堆砌术语）
- [ ] 学习目标是否问得清楚？（不是"了解 X"，而是"能用自己的话解释 X"）
- [ ] 核心机制是否回答了"为什么"？（不仅是"是什么"）
- [ ] 应用场景是否具体、可讲？（不是"可用于很多领域"）
- [ ] 至少 3 条混淆点 / 边界条件是否各自独立、互不重复？
- [ ] 自测题是否能检验"理解"而非"背诵"？
- [ ] 所有引用链接是否均为 200？（非 200 是否已剔除并说明）
- [ ] 数字、术语、归因是否与原始来源一致？（未做估算）
- [ ] 是否区分了"我的判断"和"来源原话"？

## 五、调用方式

1. 用 WorkBuddy 打开本仓库所在目录作为工作区。
2. 项目级 Skill 会被自动识别，**无需额外安装或配置**。
3. 在对话中直接说出概念名称即可，例如：

```
用 concept-learning-material 学习"主成分分析"
```

```
用 concept-learning-material 生成"蒙特卡洛模拟"的学习资料，
我已有概率论基础，重点是和解析法的区别
```

4. 生成的资料默认输出到 `learning-materials/<概念英文 slug>.html`。
   例：`learning-materials/principal-component-analysis.html`

## 六、与其他资料的关系

- 本 Skill 本身**不**包含任何具体概念的内容；
- `learning-materials/` 下已经生成的若干 HTML 文件，是按本 Skill
  三次调用得到的**结果样本**，可作为风格参考；
- 当 Skill 的输出要求与本文件描述不一致时，**以本文件为准**。

## 七、不适用范围

本 Skill **不**用于：

- 长篇综述（> 5000 字）的撰写
- 需要图表重绘、数学符号严格排版的学术笔记
- 实时性极强的资讯类内容
- 任何对**单一来源**的复述性整理（这违反 §三 的硬性约束 1）

如确需处理上述场景，请改用其他工具，并在 commit message 中注明。
