🧰 核心概念 · Core Concept

Skill（技能）

把"如何完成某类任务"打包成可复用的指令+工具集合，让 Agent 在特定场景下变得专业、可靠。

📌 一句话理解

Skill 是一份"任务说明书 + 工具配置"，告诉 Agent："当你遇到 X 类任务时，按这个流程做，用这些工具"。它把通用模型变成某领域的专家。

📦 Skill 的典型组成

📝

SKILL.md 提示词

用自然语言写清的"工作手册"——做什么、怎么做、何时调用。

🛠️

工具 / 脚本

脚本、API、MCP 服务，让 Skill 真的能动手做事。

📂

资源 / 模板

参考文档、数据、prompt 模板等"弹药库"。

🔧 常见 Skill 类型

🔌 工具型 Skill

提供操作外部系统（Git、邮箱、数据库、设计工具）的能力。

📚 流程型 Skill

固化复杂工作流，如"排版会议纪要 → 生成报告 → 上传资料库"。

🧠 领域型 Skill

把专业知识编码进去，如"金融分析 SOP"、"法律合同审查"。

🎨 创作型 Skill

专为生成内容设计：PPT、海报、视频、3D 模型……

🗂️ 一个 Skill 的最小结构示例

skills/
└── my-skill/
    ├── SKILL.md          ← 必填：描述何时调用、如何调用
    ├── scripts/          ← 可选：辅助脚本
    │   └── helper.py
    ├── references/       ← 可选：参考资料
    └── assets/           ← 可选：模板、图片、字体

💡 SKILL.md 是 Agent 识别 Skill 的"名片"，写得越清晰，触发越精准。

🌟 Skill 设计原则

✅ 单一职责

一个 Skill 只解决一类问题，避免大杂烩。

✅ 触发清晰

SKILL.md 中明确"何时用我"，让 Agent 能正确调用。

✅ 工具可复用

脚本要通用、可独立测试，方便后续修改。

✅ 自带示例

给出调用示例，能大幅提升 Agent 命中率。
