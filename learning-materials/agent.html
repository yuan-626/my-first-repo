🤖 核心概念 · Core Concept

Agent（智能体）

一个能"感知 → 思考 → 行动"的自治 AI 实体，是大模型从"对话工具"进化为"问题解决者"的关键载体。

📌 一句话理解

Agent 是一个"有目标、会思考、能执行"的 AI 实体。它不止会回答问题，还能根据目标自主规划步骤、调用工具（搜索、代码、文件操作……），最终把任务完成。

🧩 Agent 的四大核心能力

👁️

感知 Perception

接收用户输入、读取文件、观察屏幕、检索环境信息。

🧠

思考 Reasoning

由大模型驱动，将目标拆解成步骤，决定下一步做什么。

🛠️

行动 Action

调用工具（搜索、写代码、改文件、操作 API……）来改变环境。

🔁

循环 Loop

观察结果 → 反思 → 再行动，直到任务完成或达到终止条件。

⚙️ Agent 的工作循环

  1. 1
    接收目标：用户提出任务，例如"帮我调研竞品并写份报告"。
  2. 2
    规划计划：LLM 分析任务，拆出"检索 → 汇总 → 写作 → 校对"等步骤。
  3. 3
    执行动作：调用工具（Web 搜索、写文件……）实际产出结果。
  4. 4
    观察反馈：检查动作是否成功（如文件是否真的写入）。
  5. 5
    循环直到完成：未完成则回到步骤 2 重新规划。

🆚 Agent vs 普通 LLM 对话

维度 普通 LLM 对话 Agent
输出形式一段文字回答多步骤行动 + 最终结果
是否调用工具否（纯生成）是（搜索、代码、API、文件……）
主动性被动响应主动规划与迭代
任务时长秒级分钟到小时
