# docs

存放**实验报告**（Markdown / HTML / PDF）与**课程相关的非代码文档**。

## 实验报告模板

课程作业的实验报告建议包含以下章节（Markdown 编写）：

```markdown
# 作业 X.X：<标题>

- **姓名**：马元元
- **学号**：P251012217
- **课程**：统计学-Python
- **GitHub**：yuan-626
- **关联 Notebook**：`../<章节目录>/<文件名>.ipynb`

---

## 一、问题陈述

用自己的话复述问题；说明要回答的核心问题是什么。

## 二、数据说明

- 数据来源（注明链接 / 课程资料页码）
- 字段含义、单位、样本量
- 已知的数据质量问题

## 三、方法

- 用到的统计方法 / 模型
- 关键公式（手写或截图）
- 为什么选择该方法（与其他方法的对比）

## 四、过程与结果

- 关键代码片段 + 输出
- 必要的可视化（截图）
- 表格汇总核心数字

## 五、结论与局限

- 核心结论（不超过 3 条）
- 局限性与未来工作

## 六、参考资料

- 数据来源
- 引用的教材章节 / 论文
- 用到的库的官方文档
```
