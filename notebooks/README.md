# notebooks

存放**通用 Jupyter 实验记录**——不属于具体课程章节的零散实验、
跨章节的练习、或对某篇博客 / 论文的复现。

## 与课程目录的区别

| 用途 | 放在哪 |
| --- | --- |
| 与某章强相关（如"线性回归"在第三章讲过） | `03-统计建模/` |
| 跨章节的零散练习 / 通用技巧 | `notebooks/` |
| 期末综合项目 | `04-综合项目/` |

## 命名建议

```
notebooks/<日期>-<主题>.ipynb
# 例：notebooks/2026-09-06-matplotlib-排版技巧.ipynb
```
